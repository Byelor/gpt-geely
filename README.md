# Geely Help Minsk — лендинг

Одностраничный сайт услуги «модификация ГУ и установка ПО на Geely EX2» (Минск).
Чистые **HTML + CSS + JS**: без сборки, без фреймворков, без внешних библиотек.
Три файла — открываются двойным кликом и просто работают.

## Файлы проекта

| Файл | Что внутри |
|---|---|
| `index.html` | вся разметка. В начале файла — карта страницы, секции помечены `СЕКЦИЯ N` |
| `styles.css` | все стили. В начале — оглавление; цвета/шрифты/отступы — в `РАЗДЕЛ 1` |
| `script.js` | интерактив. В начале — `CONFIG` и список блоков `БЛОК N` |
| `README.md` | эта шпаргалка |

## Как открыть для просмотра

- **Быстро:** двойной клик по `index.html`.
- **Как на сервере** (рекомендуется для отладки): в папке проекта выполнить
  `python3 -m http.server 8000` и открыть http://localhost:8000

## Как опубликовать

Сайт — статика, подходит любой хостинг: GitHub Pages, Netlify (перетащить
папку в браузере), Vercel, обычный хостинг по FTP. Достаточно трёх файлов:
`index.html`, `styles.css`, `script.js`.

## 3. Добавить вопрос в FAQ

В СЕКЦИИ 10 скопируйте любой `<div class="faq__item">…</div>` и поменяйте
`id` (должны быть уникальными; следующий свободный — `q7`/`a7`):

```html
<div class="faq__item reveal">
  <h3 class="faq__heading">
    <button class="faq__q" type="button" id="faq-q7" aria-expanded="false" aria-controls="faq-a7">
      Текст вопроса<span class="faq__icon" aria-hidden="true"></span>
    </button>
  </h3>
  <div class="faq__a" id="faq-a7" role="region" aria-labelledby="faq-q7">
    <div><p>Текст ответа.</p></div>
  </div>
</div>
```

Открыт один вопрос за раз — так настроено в `script.js` (`initFaq`).

## 4. Добавить карточку в «Возможности»

СЕКЦИЯ 3 → скопируйте `<article class="card reveal">…</article>`,
замените иконку и текст. Иконка — любой inline-SVG со `stroke="currentColor"`
(цвет подхватится автоматически).

## 5. Добавить приложение в чипы

СЕКЦИЯ 3 → `<span class="chip" role="listitem">Название</span>`.

## 6. Цвета и шрифт

Всё в `styles.css` → **РАЗДЕЛ 1**. Главные «ручки»:

- `--color-accent` — единственный акцентный цвет (кнопки, ссылки, бейдж);
- `--color-bg-secondary` — фон серых секций;
- `--font-family` — стек шрифтов.

Тёмная тема включается **автоматически** по настройкам системы пользователя
(блок `prefers-color-scheme: dark` в том же разделе).

## 7. Размеры шрифтов

- Общие: токены `--fs-*` в РАЗДЕЛЕ 1 (`--fs-body` — основной текст).
- На телефонах дополнительно масштабирует правило
  `html { font-size: 17.5px }` — `styles.css`, РАЗДЕЛ 17.
- Межстрочный интервал основного текста — `line-height` в РАЗДЕЛЕ 2.

## 8. Анимации

- Скорость и плавность — токены `--dur-*` / `--ease-*` (РАЗДЕЛ 1).
- Очередь появления в списках — `--reveal-stagger` (РАЗДЕЛ 1).
- Отключить параллакс: `script.js` → `CONFIG.parallaxSpeed: 0`.
- Отключить появление секций: убрать вызов `initReveal()` в конце `script.js`.
- У людей с включённой опцией «уменьшить движение» анимации отключаются сами
  (styles.css, РАЗДЕЛ 19 — этот блок **не удалять**).

## 9. Классы-анимации (как пользоваться в HTML)

| Класс/атрибут | Эффект |
|---|---|
| `class="reveal"` | блок плавно появляется при попадании в экран |
| `data-stagger` на контейнере | его `.reveal`-дети появляются по очереди |
| `data-draw` на блоке | «дорисовка» линии-коннектора (используется на шагах) |

После появления скрипт меняет служебные классы на `is-shown` — если увидите
это в devtools, это нормально.

## 10. Фото экрана ГУ (hero и слайдер)

Вместо нарисованного макета используются фотографии. Положите файлы
в папку `img/` и проверьте пути:

  чтобы заменить, положите новый файл и поправьте путь в `src` в двух местах.
- `img/gu-before.svg` — фото **штатного** экрана для левой половины слайдера

Рекомендации к фото: горизонтальные, от 1200px по ширине, JPEG.
Подпись для скринридеров и поиска — атрибут `alt` (в hero).
Стиль рамки/тени фото — `styles.css`, РАЗДЕЛ 6 (`.unit-photo`).

## 11. Слайдер «До / После»

- Обе половины слайдера — фото: `img/gu-before.svg` и `img/gu-after.svg` (пункт 10).

# Доступность — не ломать

- `skip-link` в начале `<body>` («Перейти к содержимому»).
- Зоны нажатия интерактивных элементов ≥ 44×44px.
- FAQ: `aria-expanded` + `aria-controls`; слайдер работает со стрелок клавиатуры.
- РАЗДЕЛ 19 в `styles.css` (`prefers-reduced-motion`) — обязателен.
- Не удаляйте `<input class="ba__range">` — это и есть управление слайдером.
