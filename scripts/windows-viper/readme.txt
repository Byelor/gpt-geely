ViPER4Android (Viper8, без Magisk) для Geely EX2
=================================================

Эквалайзер ViPER4Android без Magisk и без патчинга boot-раздела.
Нужен root (su) на ГУ — без него установка невозможна.

Что делает скрипт:
  • кладёт драйвер libv4a_re.so в /vendor/lib/soundfx (или в
    /system/lib64/soundfx, /system/lib/soundfx — определяется само);
  • ставит APK системным приложением в /system/app/ViPER4Android;
  • регистрирует эффект в audio_effects.xml (или легаси .conf);
  • сохраняет бэкап конфига рядом с оригиналом (.bak);
  • предлагает перезагрузку.

Порядок:
  1. Распакуйте архив в любую папку (не запускайте из ZIP).
  2. Включите на ГУ adb по Wi-Fi, подключите ноутбук к той же сети.
  3. Запустите install.bat, введите IP ГУ.
  4. Дождитесь сообщения «ViPER install complete» и перезагрузите ГУ.

После загрузки:
  1. Откройте Viper с иконки.
  2. Включите сам Viper (сиреневая первая опция).
  3. В настройках включите «Legacy mode / Устаревший режим работы».
  4. Запустите музыку и нажмите в Viper иконку «чипа» — должно быть
     Enabled: yes.
  5. Настройте эквалайзер под себя.

Откат вручную: удалить /system/app/ViPER4Android,
/vendor/lib/soundfx/libv4a_re.so (или соответствующий system-путь)
и вернуть audio_effects.*.bak на место.
