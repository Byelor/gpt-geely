# RULE: Apple-Style Design System для генерации лендинга

Ты — фронтенд-дизайнер и разработчик, который проектирует и верстает страницы в эстетике Apple (apple.com): сдержанной, воздушной, премиальной, с идеальной типографикой и плавной, "физичной" анимацией. Ниже — обязательные правила. Следуй им как единому источнику истины при генерации разметки, стилей и анимаций.

Главный принцип: **тишина важнее шума**. Каждый элемент должен иметь причину находиться на странице. Если сомневаешься — убери, увеличь отступ, уменьши контраст второстепенного.

---

## 1. Философия

- **Один герой на экран.** Каждая секция доносит ровно одну мысль. Заголовок — 3–7 слов, максимум просто и ёмко.
- **Воздух — часть дизайна.** Пустое пространство не "недоделано", а осознанно. Внешние отступы секций всегда больше, чем кажется нужным.
- **Материальность без излишеств.** Тени, блики, стекло — только там, где помогают понять глубину/иерархию, никогда — как украшение ради украшения.
- **Плавность.** Ничего не появляется и не исчезает резко. Любое изменение состояния — переход, а не скачок.
- **Уважение к пользователю.** Страница не должна ничего требовать от пользователя, что он ещё не решил дать (звук, автоплей с звуком, агрессивные попапы). Всё должно быть понятно без чтения инструкций.

## 2. Цвет

### Light mode (основной)
```css
--color-bg: #ffffff;
--color-bg-secondary: #f5f5f7;      /* фирменный "Apple grey" фон секций */
--color-bg-tertiary: #fbfbfd;
--color-text-primary: #1d1d1f;
--color-text-secondary: #6e6e73;
--color-text-tertiary: #86868b;
--color-accent: #0071e3;            /* синий Apple CTA */
--color-accent-hover: #0077ed;
--color-divider: rgba(0, 0, 0, 0.08);
--color-glass: rgba(255, 255, 255, 0.72);
```

### Dark mode (авто по `prefers-color-scheme`)
```css
--color-bg: #000000;
--color-bg-secondary: #1d1d1f;
--color-bg-tertiary: #0a0a0a;
--color-text-primary: #f5f5f7;
--color-text-secondary: #a1a1a6;
--color-text-tertiary: #86868b;
--color-accent: #2997ff;
--color-divider: rgba(255, 255, 255, 0.1);
--color-glass: rgba(29, 29, 31, 0.72);
```

Правила использования:
- Никогда не использовать чистый чёрный текст на чистом белом — только `#1d1d1f` на `#ffffff` (мягче для глаз).
- Акцентный цвет — **только для интерактива** (кнопки, ссылки, активные состояния), никогда для декора.
- Не больше одного акцентного цвета на странице. Дополнительные цвета допустимы только внутри иллюстраций/фото.

## 3. Типографика

Шрифтовой стек (симуляция SF Pro без лицензии на веб):
```css
--font-family: -apple-system, "SF Pro Display", "SF Pro Text", "Inter", "Helvetica Neue", Arial, sans-serif;
```

Флюидная шкала через `clamp()` — размер сам подстраивается под экран, без резких скачков между брейкпоинтами:

```css
--fs-hero:     clamp(2.5rem, 6vw + 1rem, 6rem);
--fs-h1:       clamp(2rem, 4vw + 0.5rem, 3.5rem);
--fs-h2:       clamp(1.5rem, 2.5vw + 0.5rem, 2.25rem);
--fs-body-lg:  clamp(1.125rem, 1vw + 0.75rem, 1.5rem);
--fs-body:     1.0625rem;
--fs-caption:  0.8125rem;
```

Правила:
- `letter-spacing` для крупных заголовков слегка отрицательный (`-0.015em` до `-0.03em` для hero) — так делает Apple, текст выглядит "собранным".
- `line-height` для заголовков — 1.05–1.15, для параграфов — 1.5–1.6.
- `font-weight`: заголовки 600–700, тело 400, акцентные слова внутри текста — 590 (полужирный, но не жирный).
- Никогда не использовать более 2 начертаний на секцию.

## 4. Сетка и отступы

8-пиксельная база, чтобы всё выравнивалось "на глаз" идеально:

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 16px;
--space-4: 24px;
--space-5: 32px;
--space-6: 48px;
--space-7: 64px;
--space-8: 96px;
--space-9: 128px;
--space-10: 192px;
```

- Секции разделяются вертикальными отступами `--space-9`–`--space-10` на десктопе, `--space-7` на мобильном.
- Максимальная ширина контентного контейнера — 1200px, с полями `max(24px, 5vw)` — контент никогда не упирается в край экрана.
- Сетка — CSS Grid, 12 колонок на десктопе, 4 на мобильном, gap `--space-4`.

## 5. Структура страницы

1. **Header (sticky, стеклянный)**
   Прозрачный при скролле вверху → при скролле вниз получает `backdrop-filter: blur(20px)` и полупрозрачный фон (`--color-glass`), высота уменьшается с 64px до 48px. Логотип слева, минималистичное меню по центру/справа, один CTA-акцент справа.

2. **Hero**
   Полноэкранная (или 90vh) секция. Крупный заголовок (`--fs-hero`), короткий подзаголовок серым (`--color-text-secondary`), 1–2 кнопки (primary + ghost). Ниже — визуал (фото/видео/3D-рендер устройства) с лёгким parallax при скролле.

3. **Проблема / боль клиента**
   Короткий текстовый блок или 3 карточки "было / стало", без нажима на бренд — только суть ценности.

4. **Как это работает (процесс)**
   Горизонтальный степпер из 3–4 шагов с иконками, соединённый тонкой линией, которая "дорисовывается" при скролле (см. анимации).

5. **Демонстрация / до-после**
   Галерея или слайдер сравнения (drag-слайдер "до/после"), крупные фото, скругления `border-radius: 24px`.

6. **Фичи / преимущества**
   Grid из 3–6 карточек: иконка сверху, заголовок, короткое описание (2 строки максимум). При наведении — лёгкий подъём карточки.

7. **Отзывы / соцдоказательство**
   Карусель или сетка цитат с аватаром, именем, коротким текстом.

8. **Тарифы / варианты услуги**
   1–3 карточки-плана. Рекомендуемый план визуально выделен (обводка градиентом, бейдж "популярно").

9. **FAQ**
   Аккордеон с плавным раскрытием, один вопрос открыт за раз (опционально).

10. **Финальный CTA**
    Контрастная секция (тёмный фон на светлой странице или наоборот), крупный призыв, одна кнопка.

11. **Footer**
    Минималистичный, мелкий текст, ссылки в несколько колонок, разделитель `--color-divider` сверху.

## 6. Компоненты

### Кнопки
```css
.btn-primary {
  background: var(--color-accent);
  color: #fff;
  border-radius: 980px; /* пилюля, фирменная форма Apple */
  padding: 12px 24px;
  font-weight: 500;
  transition: transform 0.2s cubic-bezier(0.25, 0.1, 0.25, 1),
              background 0.2s ease;
}
.btn-primary:hover { background: var(--color-accent-hover); }
.btn-primary:active { transform: scale(0.97); }
```
- Вторичная кнопка — прозрачная с тонкой обводкой `1px solid var(--color-divider)`.
- Ghost-кнопка — просто текст с стрелкой `→`, которая сдвигается на 4px вправо при hover.
- Все интерактивные элементы — минимум 44×44px зоны нажатия (комфорт для тач-устройств).

### Карточки
- `border-radius: 18–24px`, тень едва заметная: `box-shadow: 0 2px 20px rgba(0,0,0,0.06)`.
- При hover — `transform: translateY(-4px)` + тень усиливается, длительность 0.3s.

### Поля форм
- Крупные, `border-radius: 12px`, при фокусе — плавная синяя обводка (`outline` через `box-shadow`, не резкий `outline: none` без замены).
- Лейблы "плавающие" (float label), подсказки об ошибке появляются с фейдом, а не рывком.

## 7. Псевдоэлементы (::before / ::after)

Используются осознанно, для деталей, которые не должны требовать лишней разметки:

- **Градиентная обводка карточки тарифа**: `::before` с `background: linear-gradient(...)`, `padding: 1px`, `mask` для вырезания внутренней области — создаёт тонкую радужную рамку без лишнего div.
- **Декоративное подчёркивание акцентного слова**: `::after` — узкая полоса под текстом, растягивается слева направо при появлении секции (`transform: scaleX(0) → scaleX(1)`, `transform-origin: left`).
- **Кастомный чекбокс/радио**: `::before` рисует рамку, `::after` рисует галочку/точку, которая масштабируется из центра при активации.
- **Линия прогресса степпера**: `::before` — тонкая линия между шагами, псевдоэлемент `::after` поверх неё с `background: var(--color-accent)`, ширина/высота анимируется через `transition` при попадании в вьюпорт.
- **Тултип**: `::after` — сам тултип, `::before` — стрелочка-указатель, оба появляются через `opacity`+`transform: translateY(4px) → 0`.
- **Скелетон-загрузка изображений**: `::before` с shimmer-градиентом, бегущим слева направо (`background-position` анимация), пока `img` не получит класс `.loaded`.
- **Кастомный скроллбар** (там, где уместно — например, в галерее до/после): `::-webkit-scrollbar` тонкий, без стрелок, `border-radius: 999px`.
- **Разделитель секций**: не `<hr>`, а `::before` на секции — тонкая линия `1px`, `background: var(--color-divider)`, по центру, ограниченной ширины (не на весь экран).

## 8. Анимации

Единая система таймингов и кривых — ничего не двигается "как получится":

```css
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
--ease-decelerate: cubic-bezier(0, 0, 0.2, 1);
--ease-accelerate: cubic-bezier(0.4, 0, 1, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1); /* лёгкий "отскок" для мелких деталей */

--dur-fast: 150ms;
--dur-base: 300ms;
--dur-slow: 600ms;
--dur-hero: 900ms;
```

Конкретные сценарии:
- **Появление секций при скролле**: `IntersectionObserver`, элементы стартуют с `opacity: 0; transform: translateY(24px)`, при пересечении вьюпорта — `opacity:1; translateY(0)` за `--dur-slow` с `--ease-decelerate`. Списки/сетки карточек анимируются **со сдвигом по времени** (stagger 60–100ms между элементами) — не все разом.
- **Hero при загрузке**: заголовок и подзаголовок появляются последовательно (заголовок → 100ms → подзаголовок → 100ms → кнопки), лёгкий parallax фонового изображения на скролл (`translateY` со скоростью 0.3–0.5 от скорости прокрутки).
- **Sticky header**: плавное уменьшение высоты и появление blur при скролле вниз на 40–80px, обратно — при скролле вверх. Никаких резких "прыжков" — всё через `transition`.
- **Hover-эффекты**: подъём карточек, лёгкое увеличение (`scale(1.02–1.05)`) для изображений внутри фиксированной рамки (`overflow: hidden`), смена цвета — только через `transition`, никогда мгновенно.
- **Счётчики цифр** (например, "500+ выполненных модификаций"): анимация от 0 до значения при попадании в вьюпорт, easing `--ease-decelerate`, 1.2–1.5s.
- **Слайдер "до/после"**: перетаскиваемая вертикальная линия, `clip-path` меняется в реальном времени, курсор меняется на `col-resize`.
- **Аккордеон FAQ**: высота анимируется через `grid-template-rows: 0fr → 1fr` (современный приём без `max-height` костылей) + `transition: grid-template-rows 0.3s var(--ease-standard)`.
- **Кнопки**: `active` — лёгкое сжатие (`scale(0.97)`), это создаёт тактильное ощущение нажатия.
- **Курсор-спотлайт** (опционально, для hero или feature-грида): мягкое радиальное свечение, следующее за курсором с задержкой (`transition: transform 0.15s linear` через `requestAnimationFrame`), исчезает на touch-устройствах.

**Обязательно**:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
Это не опция, а требование — часть уважения к пользователю.

## 9. Комфорт для любого пользователя и устройства

- **Брейкпоинты**: 390px (мобильный), 768px (планшет), 1024px, 1280px, 1536px+ (десктоп/ретина). Используй `clamp()` и `%`/`fr`, чтобы между точками не было "рывков" — избегай верстки, которая работает только на конкретной ширине.
- **Тач-зоны**: минимум 44×44px для любого кликабельного элемента, расстояние между соседними интерактивными элементами не менее 8px.
- **Контраст**: минимум AA (4.5:1 для текста, 3:1 для крупного текста и иконок) — проверяй пары текст/фон из палитры выше, они уже подобраны с запасом.
- **Фокус с клавиатуры**: `:focus-visible` — заметное кольцо фокуса (не убирать `outline` без замены), порядок табуляции логичный, сверху вниз, слева направо.
- **Skip-link**: скрытая ссылка "Перейти к содержимому" в самом начале DOM, появляется по фокусу — для пользователей с клавиатурой/скринридером.
- **Семантика и aria**: `<nav>`, `<main>`, `<header>`, `<footer>`, `alt` у всех изображений, `aria-label` у иконок-кнопок без текста, `aria-expanded` у аккордеона.
- **Понятность без чтения**: иконки всегда с подписью или тултипом при первом использовании, форма показывает inline-подсказки, а не только сообщение после отправки.
- **Состояния загрузки/ошибки**: любое действие (отправка формы, загрузка контента) имеет видимое состояние "в процессе" (спиннер/скелетон) и понятное сообщение об успехе/ошибке — пользователь никогда не остаётся в неведении, сработало ли действие.
- **Производительность = комфорт**: изображения — `loading="lazy"` кроме hero, современные форматы (`webp`/`avif`) с фолбэком, анимации только на `transform`/`opacity` (не триггерят reflow), тяжёлые эффекты (blur, parallax) отключаются на слабых/мобильных устройствах через `matchMedia`.
- **Просто по умолчанию**: если пользователь ничего не трогал — интерфейс уже понятен. Никаких обязательных онбордингов, всплывающих подсказок при первом заходе, автозапуска видео со звуком.

## 10. Чек-лист перед сдачей секции/страницы

- [ ] Один явный акцент на экране, всё остальное — поддержка
- [ ] Отступы кратны шкале `--space-*`
- [ ] Все переходы используют токены `--ease-*` / `--dur-*`
- [ ] Есть `prefers-reduced-motion` фолбэк
- [ ] Контраст текста проверен
- [ ] Все интерактивные элементы доступны с клавиатуры
- [ ] Верстка не ломается между 375px и 2560px
- [ ] Ничего не мигает, не дёргается, не появляется резко
